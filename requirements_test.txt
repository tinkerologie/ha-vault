# Additional testing dependencies beyond Home Assistant's requirements_test.txt
#
# Note: Core test dependencies are provided by HA's requirements_test.txt:
#   - pytest
#   - pytest-asyncio
#   - pytest-aiohttp
#   - pytest-cov
#   - pytest-timeout
#   - pytest-xdist (parallel test execution)
#   - coverage
#   - freezegun (time mocking)
#   - requests-mock
#   - respx (httpx mocking)
#
# Install with: uv pip install -r requirements_test.txt
#
# The test plugin, Home Assistant's own pytest-homeassistant, is not listed here:
# it must match the installed Home Assistant exactly, and the release the tests
# run on (2026.11.0) is not on PyPI. script/setup/bootstrap and script/test
# install it together with Home Assistant, using the version pinned in
# script/.lib/ha-test-harness.sh. It replaces pytest-homeassistant-custom-component,
# which has no release for Home Assistant 2026.11. It also pins syrupy, so don't
# pin syrupy here.
